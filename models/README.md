# Последовательная модель

`seqmodel.bin` — структурный усреднённый перцептрон, размечающий персоны и
места по токенам. Гибрид: признаками модели служат и орфография со
суффиксами, и флаги наших собственных словарей.

## Откуда

Обучена на **Collection3** — русском NER-корпусе с разметкой PER, LOC и ORG.

| | |
|---|---|
| Источник | https://huggingface.co/datasets/RCC-MSU/collection3 |
| Лицензия | в карточке датасета указана как «other» |
| Объём | train 9 301 предложение / 187 656 токенов, valid 2 153, test 1 922 |

Корпус независим и от наших словарей, и от слепого теста
`tools/bench/corpus/external/russian_pii_66k.txt`, по которому ничего не
настраивалось.

## Качество на тесте Collection3

| тип | точность | полнота | F1 |
|---|---|---|---|
| PER | 0.952 | 0.951 | **0.952** |
| LOC | 0.923 | 0.929 | **0.926** |
| ORG | 0.830 | 0.822 | 0.826 |

Абляция: **без словарных признаков** PER 0.937, LOC 0.914. То есть почти весь
сигнал несут форма слова и окончание, а словарь добавляет полтора пункта.
Именно поэтому модель узнаёт фамилию, которой нет ни в одном списке, — а
правила, стоящие на словаре, не узнают.

## Размер и скорость

30 519 признаков с ненулевым весом, семь тегов, файл **1.57 МБ**. В рантайме —
Viterbi по семи тегам, без экспонент и нормализации, только сложения.
Стоимость: около 17 микросекунд на тело в 200 байт, то есть примерно +8% к
запросу проверяющей системы.

## Как воспроизвести

```bash
pip install numpy pyarrow
curl -L -o train.txt.gz https://huggingface.co/datasets/RCC-MSU/collection3/resolve/main/data/train.txt.gz
# то же для valid.txt.gz и test.txt.gz, всё в каталог ner/
python3 tools/model/train.py ner 15 1        # обучение, около 20 секунд
python3 tools/model/export.py ner models/seqmodel.bin
python3 tools/model/verify.py ner ./_build/default/tools/model/verify_ocaml.exe
```

Последняя команда обязательна: она прогоняет одни и те же предложения через
питоновскую и окамловскую реализации признаков и сравнивает теги. Расхождение
означает, что веса применяются не к тем признакам, и модель молча
деградирует — поймать это иначе нельзя. Текущее расхождение: 4 токена из
37 579, то есть 0.011%, и все четыре из-за разной токенизации сокращений.

Без файла `seqmodel.bin` сервис работает на одних правилах, только с меньшей
полнотой на именах вне словарей.
