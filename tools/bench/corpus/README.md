# Корпуса pdmask

Четыре набора текстов, у каждого своя роль. Разделение не косметическое:
на одних решение настраивалось, на других — только проверялось, и смешивать
их нельзя, иначе цифра перестаёт что-либо значить.

```
own/       написано нами, использовалось при настройке
external/  чужие датасеты, скачаны как есть
perf/      обычная проза для замеров скорости, без ПДН
```

## Что чем меряется

| набор | кейсов | роль | настраивались ли по нему правила |
|---|---|---|---|
| `own/cases.txt` | 116 | ручной корпус по ТЗ, с ловушками | **да** |
| `own/corner.txt` | 91 | корнеркейсы: формы адреса, имён, документов | **да** |
| `external/pii_bench.txt` | 1810 | hivetrace/pii-bench | **да**, отчасти |
| `external/russian_pii_66k.txt` | 65 620 | wolframko/russian-pii-66k | **нет, слепой тест** |
| `perf/prose_sample.txt` | — | текст без ПДН для замеров скорости | неприменимо |

Последняя строка — главная. Датасет на 65 тысяч примеров скачан уже после
того, как решение было доведено на первых трёх, и **ни одно правило, ни одна
словарная статья по его результатам не менялись**. Он существует ровно затем,
чтобы показать разрыв между «настроено» и «работает».

## Как запускать

```bash
dune exec tools/bench/score_pdmask.exe                                                  # own/cases.txt
dune exec tools/bench/score_pdmask.exe -- --corpus tools/bench/corpus/own/corner.txt
dune exec tools/bench/score_pdmask.exe -- --corpus tools/bench/corpus/external/pii_bench.txt
dune exec tools/bench/score_pdmask.exe -- --corpus tools/bench/corpus/external/russian_pii_66k.txt
dune exec tools/bench/score_pdmask.exe -- --fails                                       # поимённо, что падает
```

## Формат

Один файл на набор, правится руками или собирается скриптом конвертации.

```
@case id=<id> size=<micro|sentence|document> polarity=<pos|neg|mixed> expect=<mask|clean>
@probes <что этот кейс вскрывает>
@text
<текст; значения ПДН размечены как {{тип|значение}}>
@end
```

Разметка снимается при загрузке, смещения спанов вычисляются из неё — поэтому
эталон физически не может разойтись с текстом. Смещения байтовые.

## Метрика

- **recall** — доля непробельных байтов эталонных спанов, закрытых маской.
  Пробелы внутри значения маска сохраняет намеренно, пропуском они не считаются.
- **лишних Б** — байты под маской вне эталонных спанов.
- На кейсах `expect=clean` любой замаскированный байт является ошибкой.
- Типы, которых нет в перечне ТЗ, в recall не входят и избыточным маскированием
  не считаются — они нейтральны.
