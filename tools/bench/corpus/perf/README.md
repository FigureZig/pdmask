# Текст для замеров скорости

`prose_sample.txt` — 200 КБ обычной русской прозы без персональных данных.
Источник: статьи русской Википедии, лицензия CC BY-SA 4.0. Обрезано по границе
символа UTF-8.

Зачем отдельный файл. Тело для нагрузочных замеров до этого собиралось
повторением корпуса ПДН, и получался худший случай: 6693 кандидата на 400 КБ,
замаскированный спан на каждые восемьдесят байт. Ни деловая переписка, ни
обращение в банк так не выглядят. Реалистичное тело собирается из этой прозы с
вкраплением кейса из корпуса примерно раз в два килобайта.

```bash
dune exec tools/bench/prof_stage.exe -- pipeline 40 409600         # плотное тело ПДН
dune exec tools/bench/prof_stage.exe -- pipeline 60 409600 prose   # реалистичное
```

Обе цифры репортятся вместе: подменять худший случай удобным нельзя, но и
выдавать корпус, повторённый тридцать раз, за профиль нагрузки — тоже.
