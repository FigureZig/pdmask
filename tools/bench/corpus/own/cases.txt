# Корпус pdmask. Один файл, правится руками, ничем не генерируется.
#
# Формат:
#   @case id=<id> size=<micro|sentence|document> polarity=<pos|neg|mixed> expect=<mask|clean>
#   @probes <что этот кейс вскрывает>
#   @text
#   <текст, сколько угодно строк; значения ПДН размечены как {{тип|значение}}>
#   @end
#
# Разметка снимается при загрузке, смещения спанов вычисляются из неё — поэтому
# эталон физически не может разойтись с текстом. Смещения байтовые.
#
# Все ПДН синтетические: имена из словарей проекта, контрольные суммы
# посчитаны, домены из RFC 2606. Настоящих персональных данных здесь нет.
