# Корпус корнеркейсов pdmask. Правится руками, ничем не генерируется.
#
# Формат тот же, что у cases.txt: {{тип|значение}}, смещения считаются из разметки.
#
# Что здесь собрано и почему:
#   - адресные сокращения по номенклатуре ФИАС (пр-т, б-р, ш., туп., мкр., кв-л,
#     вл., лит., ком., п., эт.) — служебное слово остаётся видимым, под маску
#     уходит только значение;
#   - номер дома во всех живых формах: через дробь, с литерной буквой, с
#     корпусом и строением, через дефис;
#   - названия улиц, которые сами состоят из чисел и дефисов;
#   - ФИО: двойные фамилии, инициалы с двух сторон, отчества на -ич и -ична,
#     тюркские оглы и кызы, корейские имена, фамилии-омонимы обычных слов,
#     косвенные падежи;
#   - документы во всех записях, которые встречаются в переписке;
#   - негативные случаи, где маскировать НЕЛЬЗЯ по существу, а не по стилю.
#
# Юридическая опора негативных случаев (152-ФЗ, ст. 3):
#   персональные данные — это информация, относящаяся к определённому или
#   определяемому ФИЗИЧЕСКОМУ лицу. Поэтому НЕ являются персональными данными
#   и маскированию не подлежат:
#     - ИНН юридического лица (10 цифр; у физлица 12) — cor-neg-04;
#     - ОГРН (13 цифр), КПП, БИК, расчётный счёт организации — cor-neg-05..08;
#     - адрес отделения банка как места оказания услуг — cor-neg-09;
#     - единый номер поддержки и ролевой почтовый ящик: они не идентифицируют
#       физическое лицо — cor-neg-17, cor-neg-18.
#   Публичная персона в публичном же контексте выведена из-под маскирования
#   отдельным требованием ТЗ — cor-neg-10.
#
# Все данные синтетические: контрольные суммы ИНН, СНИЛС и карты посчитаны,
# домены из RFC 2606, номера не принадлежат никому.
